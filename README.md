# FarmWhisper

FarmWhisper is an initial repository scaffold for a farm monitoring and connectivity project.

## Repository layout

- cad/: CAD source files and mechanical design assets in OpenSCAD format.
- docs/: Project documentation and technical design notes.
- firmware/: Embedded firmware sources and build-related configuration.
- hardware/: Hardware design notes, schematics, and interface documentation.
- tools/: Helper scripts and utilities.
- tests/: Automated tests and validation assets.

## Conventions

- Keep CAD source files in OpenSCAD format (.scad).
- Do not commit generated 3D export artifacts such as .stl, .3mf, or .gcode.
- Keep build artifacts out of version control.
